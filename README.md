# A/B Testing Analysis - Cookie Cats 

## Описание проекта

Анализ A/B теста для мобильной игры **Cookie Cats**.  
Сравнение двух версий игры с **гейтом на уровне 30** (gate_30) и **гейтом на уровне 40** (gate_40).

**Цель:** Определить, какая версия лучше удерживает игроков и не снижает игровую активность.

## Данные

- **Источник:** [Kaggle - Mobile Games A/B Testing](https://www.kaggle.com/datasets/yufengsui/mobile-games-ab-testing)
- **Размер выборки:** 90,189 пользователей
- **Группы:**
  - `gate_30` (контрольная) — 44,700 пользователей (49.56%)
  - `gate_40` (тестовая) — 45,489 пользователей (50.43%)
  
- **Файлы репозитория:**
 - **game_with_cats_jupiter.ipynb** Jupyter-ноутбук для ETL и статистической проверки гипотез. Включает очистку данных, оценку сопоставимости групп, а также статистическую проверку значимости различий по Retention и суммарным игровым раундам между версиями приложения.
 - **cookie_cats.sql** Исследовательский анализ данных на SQL. Расчет распределения по версиям, Retention Rate по версиям, статистика по игровым сессиям, сегментация пользователей, когортный анализ и проверка на несоответствие соотношения выборок.
 - **cookie_cats.pbix** Интерактивный дашборд Power BI. Визуализация средних значений игровых раундов, количества пользователей по версиям, графиков удержания (Retention) по дням, а также взаимосвязи между удержанием и общим количеством раундов в разрезе версий.

### Колонки:
| Колонка | Описание |
|---------|----------|
| `userid` | Уникальный идентификатор пользователя |
| `version` | Версия игры (gate_30 / gate_40) |
| `sum_gamerounds` | Общее количество сыгранных раундов |
| `retention_1` | Вернулся ли игрок на 1-й день (True/False) |
| `retention_7` | Вернулся ли игрок на 7-й день (True/False) |

---

## Методология

### Проверка нормальности
- Распределение `sum_gamerounds` **НЕ нормальное** 
- Использованы **непараметрические** тесты

### Статистические тесты

| Метрика | Тип данных | Тест | Результат |
|---------|-----------|------|-----------|
| **Retention** | Бинарные (0/1) | Хи-квадрат | Значимо |
| **Game rounds** | Непрерывные (скошенные) | t-test | Не значимо |
